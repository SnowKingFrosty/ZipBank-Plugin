🆕 NEW FEATURE: TRANSACTION HISTORY
────────────────────────────────────────────────────────────────────────────

What it does:
• Players can view their last 28 transactions in the ATM
• Shows transaction type, date/time, amount, and balance
• Accessed via "Transaction History" button (book icon) in ATM GUI
• Complete transaction logging for all money transfers

Supported transaction types:
✓ Cash Deposit       (physical cash → bank)
✓ Cash Withdrawal    (bank → physical cash)
✓ Vault Deposit      (wallet → bank)
✓ Vault Withdrawal   (bank → wallet)

🔧 INSTALLATION (3 EASY STEPS)
────────────────────────────────────────────────────────────────────────────

1. Stop your Minecraft server
2. Copy zipbank-1.0.0.jar to server plugins/ folder
3. Restart the server

That's it! The plugin will automatically:
• Create the transactions database table
• Start logging all transactions
• Make the Transaction History button available
